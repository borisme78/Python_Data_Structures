# Структури даних Python

Навчальні завдання з обробки рядків і текстових файлів, списків, словників та сортування даних у Python.

## Вміст

| Файл | Опис | Вхідний файл |
| --- | --- | --- |
| `task_6_5.py` | Виділення числа з рядка `X-DSPAM-Confidence` та перетворення його на `float`. | Не потрібен |
| `task_7_1.py` | Читання тексту й виведення його великими літерами. | `words.txt` |
| `task_8_4.py` | Формування відсортованого списку унікальних слів. | `romeo.txt` |
| `task_9_4.py` | Пошук адреси відправника з найбільшою кількістю повідомлень за рядками `From `. | `mbox-short.txt` |
| `task_10_2.py` | Підрахунок повідомлень за годинами відправлення та виведення результату в порядку годин. | `mbox-short.txt` |

Текстові файли для вправ уже містяться в цій папці.

## Запуск

Потрібен Python 3. Додаткові бібліотеки не потрібні.

Із кореневої папки проєкту перейдіть до цієї папки, щоб скрипти знаходили текстові файли за їхніми назвами:

```sh
cd Python_Data_Structures
python3 task_8_4.py
```

На запит `Enter file name:` введіть `romeo.txt`. Для інших завдань використовуйте назви вхідних файлів із таблиці.

Завдання 6.5 не потребує введення:

```sh
python3 task_6_5.py
```
